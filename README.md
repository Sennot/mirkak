# Spout2 Layout Feed

Geode-мод для Geometry Dash 2.2081 (Windows, Geode 5.8.2).

- **На твоём мониторе** уровень идёт в Layout Mode: без декораций, цветов, свечения, частиц и шейдеров.
- **В OBS через Spout2** идёт обычный уровень, со всеми декорациями, шейдерами и эффектами камеры 2.2.

Сам уровень мод не меняет: в отличие от Layout Mode в GDH, триггеры цвета, альфы, шейдеров и камеры
работают как обычно. Отличается только картинка на экране.

## Как это работает

Для каждого кадра (хук `CCEGLView::swapBuffers` с приоритетом `FirstPre`):

1. Игра как обычно рисует кадр в back buffer.
2. Этот кадр отправляется в Spout2 (`SendFbo`, копия на GPU через GL/DX interop).
3. Если открыт уровень и Layout Mode включён, сцена рисуется ещё раз поверх, в layout-стиле,
   и на монитор попадает уже эта версия.
4. Меню других модов (ImGui, Mega Hack) рисуются после этого: они есть на экране, но не в OBS.

### Почему это не грузит процессор

Повторная отрисовка не трогает объекты уровня и не пересчитывает их цвета:

- **Batch-ноды объектов** рисуются своим GLSL-шейдером из уже загруженных в видеопамять вершин.
  Роль каждого квада (оставить, скрыть, цвет объекта, цвет детали) лежит в маленькой текстуре,
  1 байт на квад. Вершинный шейдер читает её по `gl_VertexID / 4`, перекрашивает объект или
  выносит скрытый квад за пределы экрана, так что до растеризации он не доходит.
- Маска пересобирается только когда меняется состав batch-ноды (появились/ушли объекты).
  В остальных кадрах это одно сравнение массива указателей, то есть почти ноль CPU.
- Роль спрайта считается один раз при загрузке уровня (`PlayLayer::addObject`) и кэшируется.
- Шейдеры 2.2 выключаются только на время второго прохода (`m_usesShaders = false`),
  поэтому в OBS они остаются.
- Фон заменяется очисткой экрана нужным цветом, земля перекрашивается на время прохода
  (это пара десятков спрайтов), а потом всё возвращается как было.

## Настройки

| Настройка | По умолчанию | Что делает |
|---|---|---|
| Enable Spout2 sender | вкл | Отправка кадров в OBS |
| Sender name | `Geometry Dash` | Имя источника в OBS (Spout2 Capture) |
| Capture cursor | вкл | Курсор только в Spout2 |
| Enable Layout Mode | вкл | Layout Mode на экране. Переключается клавишей **F6** |
| Hide decoration | вкл | Скрывает декорации и no-touch объекты (тот же список ID, что в GDH) |
| Remove object colors | вкл | Объекты рисуются цветами ниже вместо цветовых каналов |
| Show invisible objects | вкл | Игнорирует альфа-триггеры и fade |
| Disable additive blending | вкл | Объекты на blending-каналах рисуются обычным смешиванием |
| Hide glow / particles / middleground | вкл | Свечение, частицы, средний план |
| Disable shaders | вкл | Шейдер-триггеры только на экране |
| Цвета | как в GDH | Объект, деталь, фон, земля, линия |
| Debug logging | выкл | Подробные логи, см. ниже |

## Debug logging

Включи **Debug logging** в настройках мода и открой консоль Geode или файл лога.

- При старте: версия мода, все настройки, драйвер OpenGL (vendor/renderer/version/GLSL).
- Spout2: режим шаринга. `GPU texture sharing` значит всё хорошо. Если там CPU copy или
  shared memory, будет предупреждение: GD и OBS должны работать на одной видеокарте.
- На уровне: сколько объектов зарегистрировано, сколько из них декорации, сколько batch-нод
  отслеживается, подавлены ли шейдеры.
- Раз в N секунд строка `[stats]`: FPS, время Spout и Layout на CPU (среднее и максимум)
  и на GPU (асинхронные timer queries, кадр не ждут), сколько квадов нарисовано и скрыто,
  процент кадров, где маска взята из кэша.
- Ошибки OpenGL с указанием места (`layout::render`, `renderer::updateFlags`, ...), с ограничением частоты.
- Ошибки компиляции шейдера выводятся полностью. Если шейдер не собрался, Layout Mode продолжает
  работать без перекраски объектов, а в логе написано почему.

## Сборка

Мод собирается в GitHub Actions (`.github/workflows/build.yml`, `geode-sdk/build-geode-mod`,
SDK 5.8.2, Win64). Готовый `.geode` лежит в артефакте `Spout2LayoutFeed-Windows`.

В OBS: источник **Spout2 Capture**, sender `Geometry Dash`.

## Ограничения

- Layout Mode работает только в обычных уровнях (`PlayLayer`), не в редакторе и не в его плейтесте.
- Встроенный счётчик FPS из cocos (`Show FPS` в настройках GD) рисуется только в кадре для OBS.
- Если какой-то мод что-то делает в `visit()` каждого кадра, при включённом Layout Mode
  это будет происходить дважды за кадр.
